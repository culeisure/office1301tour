# 1301호 사무실 가구 배치

버전 1 원래 확정본과 버전 2 최신 배치를 선택해 보는 정적 웹사이트입니다.

- `index.html`: 버전 선택
- `v1.html`: 원래 확정본 (업무 책상 17석)
- `v2.html`: 최신안 (홀 9석, 대표실 1석 별도, 메인 회의실 8석, 소회의실 6석)
- `v1-layout.*`, `v2-layout.*`: 도면과 JSON 다운로드

HTML을 열어 가구를 이동·회전하고 JSON으로 저장할 수 있습니다. 수정 내용은 서버에 자동 저장되지 않으며 다른 기기에서 사용하려면 JSON을 불러오세요.

방 깊이·문·기둥 돌출·가전 외곽은 실측 확인이 필요한 배치 검토 도면입니다. 공개 GitHub Pages 사이트입니다.
