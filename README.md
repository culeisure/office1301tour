# 1301호 사무실 투어

확정 가구 배치를 기준으로 만든 사무실 3D 투어입니다. GitHub Pages로 배포됩니다.

- `index.html` 안내 페이지
- `office-video-tour.html` / `office-video-tour.mp4` 동영상 투어 (1920×1080, 24fps, 약 28초, 6개 장면, 배경음악 포함)
- `office-360-tour.html` 고화질 360° 투어 (Blender 렌더, 4개 지점)
- `office-3d-tour.html` 3D 자유이동 투어 (Three.js r128, 가구 편집·배치 저장)
- `office-layout-final.html` / `.json` 가구 배치 확정본 (2D)
- `img/` 렌더 이미지와 배치도

투어 파일은 이미지와 라이브러리를 내장하고 있어 서버 없이도 열립니다.
Blender 원본(`사무실_3D_원본.blend`, 53MB)과 시안 A01~A05 반복본은 저장소에 포함하지 않았습니다.

## 조작

- 360° 투어: 드래그로 둘러보기, 지점 이름을 눌러 이동, 휠로 확대
- 3D 투어: 드래그로 시선 이동, W/A/S/D 또는 방향키로 이동, 화면 아래 이동 버튼, 가구 목록에서 선택 후 위치·높이·회전 수정, 저장은 배치 JSON 내려받기

## 한계

- 전체 길이 14.45m와 확정 배치의 바닥 좌표를 사용. 방별 깊이, 천장 높이, 기둥 치수는 실측 전 가정값
- 가구는 사진 기반 근사 모델. 측량 결과나 시공 도면이 아님
- 3D 투어에서 편집한 배치는 360° 화면에 자동 반영되지 않음
